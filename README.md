# Portfólio — Acksel Young

Portfólio desenvolvido em React para apresentar minhas habilidades, projetos e formas de contato.
A proposta é ser uma página simples, rápida e direta, mostrando meu trabalho como desenvolvedor.

🔗 Acesse o portfólio online:
 https://ackselyoung98.github.io/Portfolio/



  Tecnologias Utilizadas
	•	React
	•	JavaScript
	•	CSS
	•	Mock de dados (mock.js) para simular informações de projetos e habilidades



  Funcionalidades
	•	Seção inicial com apresentação
	•	Listagem dos meus projetos
	•	Habilidades exibidas em cards
	•	Seção de contato
	•	Layout responsivo
	•	Deploy via GitHub Pages



  Como rodar o projeto
  npm install
  npm start

  O projeto ficará disponível em: http://localhost:3000
